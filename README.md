## Лабораторная работа 5

`labs/lab5.ipynb` решает вариант 8: уравнение теплопроводности с членом `c*u`, условием Неймана слева и Дирихле справа. В ноутбуке есть выводы граничных формул, сравнение трёх временных схем и трёх аппроксимаций границ, графики, погрешности и исследование порядков сходимости.

Реализация находится в `src/nm/parabolic.py`. Для запуска установите проект и ядро Jupyter:

```sh
python -m pip install -e ".[dev]" ipykernel
```

Откройте `labs/lab5.ipynb` в Jupyter или редакторе с поддержкой ноутбуков и выполните ячейки сверху вниз. В репозитории уже сохранены результаты расчётов и графики.

Проверка численных методов:

```sh
python -m pytest tests/test_parabolic.py -v
```

Тесты проверяют сходимость всех девяти сочетаний схем и граничных аппроксимаций, общий порядок границ на отдельном точном решении и учёт `c*u` в ограничении шага явной схемы.
